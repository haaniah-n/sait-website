# SAIT Website Redesign

A modern, responsive website prototype for the **Students Association of Information Technology (SAIT)**, Division of IT, School of Engineering, CUSAT.

Built for the **SAIT Website Redesign Challenge** with a focus on clean design, accessibility, responsiveness, and student-community engagement.

## Live Website

[View the deployed website](https://sait-website-two.vercel.app/)

## Highlights

- Responsive desktop and mobile experience
- Light and dark themes
- Interactive SAIT ecosystem
- Events and moving galleries
- Student project showcase
- Careers and opportunities
- Alumni and achievements
- Notifications
- Student Activity Logger prototype
- Accessible contrast and reduced-motion support

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Lucide Icons
- Vercel

## Run Locally

```bash
git clone https://github.com/haaniah-n/sait-website.git
cd sait-website
npm install
npm run dev
```

## Prototype Note

This is a frontend prototype created for the SAIT Website Redesign Challenge. Some names, events, projects, alumni stories, achievements, opportunities, and activity records are illustrative/mock content.
